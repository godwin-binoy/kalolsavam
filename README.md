# Mala Sub-District Kalolsavam

Official on-premise festival web desk for **St. Antony's Higher Secondary School, Mala**.

## Features
- **Material You + Frosted Glassmorphism**: Translucent frosted card surfaces with backdrop blur.
- **Festive Category Cards**: Colorful category banners (`HS GENERAL`, `HSS GENERAL`, `HS ARABIC`, `HS SANSKRIT`) with custom iconography, action rows, and watermark art.
- **Live Stage Tracker**: Real-time chest number updates, green room queues, and stage statuses.
- **Tabulation & Scoreboard**: Instant publication of verified results and school point tallies.
- **Pre-paint Theme Engine**: Instant zero-flash dark/light mode toggle.

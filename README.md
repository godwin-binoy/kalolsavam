# Mala Sub-District Kalolsavam

Official festival on-premise information desk for **St. Antony's HSS Mala**.

## Key Highlights
- **Design System**: Material You tokens + Frosted Glassmorphism (`backdrop-filter: blur()`).
- **Colorful Festival Cards**: Category cards (`HS GENERAL`, `HSS GENERAL`, `HS ARABIC`, `HS SANSKRIT`) with custom watermarks, badges, and action pills.
- **Dedicated Vector Assets**: All vector icons and card watermarks live in `res/svg/`.
- **Zero-Flash Theme Boot**: Dark/light theme state is pre-painted before CSS loads.
